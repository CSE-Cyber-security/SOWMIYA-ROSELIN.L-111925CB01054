# Factorial Program in C

## Aim
To write a C program to find the factorial of a given number.

## Description
This program takes a number as input and calculates its factorial using a `for` loop.

## Formula
Factorial of n = n × (n-1) × (n-2) × ... × 1

## Example
For n = 5:

5! = 5 × 4 × 3 × 2 × 1 = 120

## Input
Enter a number: 5

## Output
Factorial of 5 = 120
