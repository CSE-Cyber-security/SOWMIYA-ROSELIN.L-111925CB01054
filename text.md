# DAILY EXPENSE TRACKER

## 1. Introduction
Daily Expense Tracker is a simple C programming
project used to manage daily expenses.

## 2. Objective
- Record daily expenses.
- View expense details.
- Calculate total expenses.
- Manage spending.

## 3. Software Requirements
- Programming Language: C
- Compiler: GCC
- Editor: VS Code

## 4. Features
1. Add Expense
2. View Expenses
3. Calculate Total
4. Exit

## 5. Concepts Used
- Structures
- Arrays
- Loops
- Switch Case
- Conditional Statements

## 6. Sample Data
Food       - Rs. 150
Travel     - Rs. 50
Shopping   - Rs. 300
Education  - Rs. 200
Bills      - Rs. 500

Total = Rs. 1200

## 7. Advantages
- Easy to use.
- Saves time.
- Helps manage money.
- Tracks daily spending.

## 8. Conclusion
The Daily Expense Tracker helps users record
and calculate their daily expenses using C.
It is a simple and useful mini project.
