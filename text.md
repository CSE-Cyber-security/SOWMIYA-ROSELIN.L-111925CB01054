
# Simple Calculator Program

## Description
This program performs basic arithmetic operations
using the C programming language.

## Algorithm
1. Start the program.
2. Read the first number.
3. Read the operator.
4. Read the second number.
5. Use a switch statement to perform the operation.
6. Display the result.
7. Stop the program.

## Conclusion
The calculator successfully performs addition,
subtraction, multiplication, and division.
It also handles division by zero and invalid operators.
